# Repository rules

- npm workspaces + Turborepo. Install with `npm ci`; preserve `package-lock.json`. Read package manifests before assuming library versions. No dependency upgrades/downgrades without a task requiring them.
- Admin: Next.js App Router, React 19, TypeScript 6, Tailwind v4 CSS-only. Animate UI **Base UI** components only; no Radix variants or `tailwind.config.js`. Keep motion to simple fade/slide; preserve accessibility.
- API: Hono/OpenAPI on Cloudflare Workers, D1/Drizzle, private R2, Queues, Durable Objects. No Node-only runtime APIs. Use `src/lib/router.ts:createRouter()` for all routers; preserve the shared error format.
- Zod v4: use current APIs (`z.uuid()`, `z.url()`). Do not copy v3-specific patterns without checking installed APIs.
- Features own implementation: `apps/api/src/modules/<feature>`, `apps/admin/src/features/<feature>`. Shared components/config/hooks/utils live outside features only when genuinely shared. No empty future domains or sample business features.
- API infrastructure also lives under `src/modules/`: `queue`, `realtime`, `storage`, `middleware`, `cron`. Keep each module in one location, including routes and runtime handlers. Only shared configs, DB/schema, helpers and types stay outside; `app.ts`/`index.ts` compose module entrypoints.
- Cross-module synchronous calls use the owning module's public service; do not import another module's private routes/repository. Async side effects use typed jobs plus transactional outbox. Keep invariants requiring atomicity inside one D1 batch; do not make financial consistency accidentally eventual.
- DB schemas: `apps/api/src/db/schema/<domain>.ts`, re-export from `index.ts`. Use Drizzle for domain writes. Tenant predicates, permission checks and DB constraints remain mandatory; an ORM provides no automatic tenant isolation.
- `outboxStatement(db, job)` and `commitJobOnce(db, id, queries)` accept Drizzle queries. Compose business writes + outbox in the same `db.batch()`. Consumers must tolerate duplicates; external effects need provider idempotency keys.
- Shared contracts: platform-neutral Zod schemas/inferred types in `packages/common/src/schemas/<domain>.ts`, explicit package subpath exports. No Node/Cloudflare/React dependencies, secrets or DB entities. Prefer `@edu/common/<domain>` imports.
- API JSON request/response contracts belong in common. Backend OpenAPI and admin/mobile callers import the same contract; do not duplicate DTOs or invent Axios response types. Axios generics alone do not verify backend compatibility; parse shared response schemas at the client boundary. Add generated endpoint typing when endpoint breadth justifies it, not a second handwritten endpoint registry.
- Migration generation is serialized: rebase onto the integration branch, then one owner runs `npm run db:generate --workspace @edu/api`. Review generated SQL/journal/snapshots, especially table rebuilds/data copies. Never rewrite applied migrations. Schema-only file moves must not create migrations.
- Update local/staging/production Wrangler files together. `tests/env.test.ts` checks binding/variable/queue/schedule parity; environment resource names/IDs/values intentionally differ. Never target remote resources without explicit authorization.
- Keep PDF/Excel/template-heavy libraries out of core API until measured. Inspect dry-run gzip size/startup CPU; add a separate task Worker only when needed. Service Bindings avoid public HTTP, not latency or runtime/resource limits.
- Auth disabled means fail closed, not bypass. Never log credentials/bodies/tickets; never publicly cache tenant-private data. Preserve bounded streaming uploads and durable failed-job archival.
- Root Prettier: four spaces. ESLint stays app-local. Run `npm run format`, `npm run test`, `npm run typecheck`, `npm run lint`, `npm run build` before handoff. Add regression checks for nontrivial logic.
- No commit, push, cloud provisioning, deployment, remote migrations or destructive cleanup without explicit user authorization. Preserve unrelated work. Do not spawn agents unless explicitly requested.
